## Brand Design System

### Design Principles

1. **Warmth Over Sterility** - Every choice should add humanity, not remove it. Use warm colors, rounded corners, and generous spacing.

2. **Clarity Over Cleverness** - Be distinctive, but never at the cost of clear communication. The goal is understanding.

3. **Substance Over Trend** - Choose timeless over trendy, depth over decoration. This brand should feel relevant in 5 years.

4. **Confidence Without Arrogance** - Authority through demonstrated expertise, not intimidation. Approachable but not casual about quality.

5. **Professional Approachability** - Sophisticated but never stuffy. Expert but never distant. Like a brilliant colleague you'd want to work with.

6. **Technical + Human** - Balance the technical credibility (Teal, data, precision) with human warmth (Terracotta, personality, stories).

## Typography

### Font Stack

**Display/Headings: Fraunces**
- Sophisticated serif with personality
- Use for all headings (H1-H4), pull quotes, key statistics
- Google Fonts: https://fonts.google.com/specimen/Fraunces

**Body Text: Inter**
- Clean, highly readable sans-serif
- Use for all body text, navigation, buttons, UI elements
- Google Fonts: https://fonts.google.com/specimen/Inter

**Code/Technical: JetBrains Mono**
- For technical content, code snippets
- Google Fonts: https://fonts.google.com/specimen/JetBrains+Mono

**Handwritten Accent: Caveat**
- Use VERY sparingly for personal touches only
- Personal signatures, short annotations (2-4 words max)
- Google Fonts: https://fonts.google.com/specimen/Caveat
- Weight: 500 (Medium)
- Size: 20-24pt for annotations, 28-32pt for signatures/quotes

### Typography Usage Rules

**When to Use Fraunces (Serif):**

✅ Always use for:
- Page titles (H1)
- Section headings (H2, H3, H4)
- Pull quotes
- Large statistics (the number itself)
- Logo/brand name

✅ Sometimes use for:
- Emphasis within body text (1-3 words, italic)
- Special callouts or featured text
- Testimonial attribution

❌ Never use for:
- Body paragraphs (hard to read at length)
- Navigation menus
- Buttons
- Forms or UI elements
- More than 2-3 lines of continuous text

**When to Use Inter (Sans-Serif):**

✅ Always use for:
- Body text (paragraphs, lists, descriptions)
- Navigation
- Buttons and CTAs
- Forms and input fields
- Captions and metadata
- UI elements (cards, tags, labels)

**When to Use JetBrains Mono (Monospace):**

✅ Always use for:
- Code snippets
- Technical data (hex codes, URLs, IDs)
- Configuration examples
- API references

❌ Never use for:
- Regular text content
- Headings
- Navigation

**When to Use Caveat (Handwritten):**

✅ Sparingly use for:
- Your signature
- Short personal notes (max 1 sentence)
- Annotations on diagrams
- Emphasis in informal contexts (social media)

❌ Never use for:
- Professional documents
- Headings
- Body text
- Anything over 1 sentence

### Typography Scaling (Responsive)

**Desktop (≥1200px):**
- H1: 2.25rem (36pt) — *Original brand spec: 72pt, scaled down for blog*
- H2: 1.75rem (28pt) — *Original brand spec: 48pt*
- H3: 1.5rem (24pt) — *Original brand spec: 32pt*
- H4: 1.25rem (20pt) — *Original brand spec: 24pt*
- Body: 1rem (16pt)
- Body Large: 1.125rem (18pt)

**Tablet (768px - 1199px):**
- H1: 2rem (32pt)
- H2: 1.65rem (26pt)
- H3: 1.35rem (22pt)
- H4: 1.2rem (19pt)
- Body: 1rem (16pt)

**Mobile (<768px):**
- H1: 1.75rem (28pt)
- H2: 1.5rem (24pt)
- H3: 1.25rem (20pt)
- H4: 1.125rem (18pt)
- Body: 1rem (16pt) — *Never go below 16pt*

### Typography Hierarchy & Emphasis

**Creating Visual Hierarchy:**

1. **Most Important** → H1 in Fraunces (large) + Teal or Terracotta color
2. **Very Important** → H2 in Fraunces + optional color accent
3. **Important** → H3 in Fraunces OR Inter Bold
4. **Standard** → Inter Regular, 16pt
5. **De-emphasized** → Inter Regular, 14pt, Warm Gray color

**Emphasis Techniques:**

For body text:
- **Bold** (Inter Semi-Bold 600) for strong emphasis
- *Italic* (Inter Italic) for subtle emphasis or voice
- Teal color for links
- Terracotta color for key facts/numbers (use sparingly)

For sections:
- Border-left in Teal or Terracotta (4px)
- Background in Sage Green at 20% opacity
- Increased padding + subtle shadow

**Never:**
- Use ALL CAPS for more than 2-3 words (taglines only)
- Underline text that isn't a link
- Use more than 2 emphasis techniques at once
- Use red for anything except errors

## Color Usage Guidelines

### When to Use Deep Teal

**Use for:**
- Primary call-to-action buttons
- Navigation links and active states
- Important interactive elements
- Data visualization (first color in charts)
- Technical/analytical content emphasis

**Why:** Teal conveys trust, professionalism, and technical capability.

### When to Use Deep Terracotta

**Use for:**
- Key statistics and numbers
- Important highlights and callouts
- Secondary CTAs or emphasis
- Pull quote accents
- Personal/human touches

**Why:** Terracotta adds warmth, personality, and draws the eye.

### Color Decision Framework

**"Should this feel technical or personal?"**
- Technical/professional → Teal
- Warm/personal → Terracotta

**"What's the hierarchy?"**
- Primary action → Teal button
- Secondary action → Terracotta button or Teal outline button
- Tertiary → Text link in Warm Gray

**"Is this content or decoration?"**
- Content that matters (stats, key points) → Terracotta
- Functional elements (buttons, nav) → Teal
- Background/container → Sage Green or Soft Cream

### UX Principles for Color Usage

**60-30-10 Rule:**
- 60% neutral (Soft Cream, Warm Charcoal)
- 30% secondary (Sage Green, Warm Gray)
- 10% accent (Teal + Terracotta combined)

**Affordance:**
- Only interactive elements should use bright accent colors
- Non-interactive content should use neutral or muted colors
- Avoid making non-clickable things look clickable

**Spacing Scale:**
- `--spacing-xs`: 4px
- `--spacing-sm`: 8px
- `--spacing-md`: 16px
- `--spacing-lg`: 24px

### Margins

- **Desktop**: 64px horizontal
- **Tablet**: 32px horizontal
- **Mobile**: 24px horizontal

### Vertical Rhythm

- Space between sections: 64px (3xl) or 96px (4xl)
- Space between related elements: 24px (lg) or 32px (xl)
- Space between text blocks: 16px (md)
- Space between paragraphs: 24px (lg)

### Spacing Scaling (Responsive)

**Desktop**: Full spacing scale  
**Tablet**: Reduce by ~25%  
**Mobile**: Reduce by ~40-50%

Example:
- Section margin: 96px (desktop) → 72px (tablet) → 48px (mobile)
- Card padding: 32px (desktop) → 24px (tablet) → 20px (mobile)

## Translation Guidelines

### Language Pair: English ↔ Spanish

When translating content between English and Spanish, follow these important guidelines:

### Title Capitalization

**English (Title Case):**
- Capitalize major words in titles
- Example: "The Journey from Dead Languages to AI"

**Spanish (Sentence Case):**
- Only capitalize the first word and proper nouns
- **WRONG:** "El Viaje desde Lenguas Muertas a IA"
- **CORRECT:** "El viaje desde lenguas muertas a IA"

**Exception:** Spanish titles in formal documents may use title case, but for blog posts and web content, use sentence case.

### Punctuation Differences

**Quotation Marks:**
- English: "double quotes"
- Spanish: Can use "comillas inglesas" or «comillas españolas»
- Preference: Use "comillas inglesas" for consistency with code/tech content

**Question & Exclamation Marks:**
- Spanish requires opening marks: ¿ and ¡
- Example: "¿Cómo puedo ayudar?" not "Como puedo ayudar?"

**Spacing:**
- Spanish uses space before colons in some cases
- En dash: Use — (em dash) without spaces in both languages

### Common Translation Patterns

**Technical Terms:**
- Keep English terms when widely used in Spanish tech contexts
- Examples: "AI" → "IA", "machine learning" → "machine learning" (or "aprendizaje automático")
- "prompt" → "prompt" (anglicism accepted in AI context)

**Tone Consistency:**
- Maintain the same level of formality/informality
- Spanish uses "tú" (informal) for blog content, not "usted" (formal)
- Keep the warm, approachable tone in both languages

**Cultural Adaptations:**
- Adapt examples and references for Spanish-speaking audience when relevant
- Keep European Spanish spelling (not Latin American)
- Examples: "ordenador" (Spain) not "computadora" (Latin America)

### File Organization

**English content:**
- Location: `/content/en/`
- Tag: `tags: [en]`

**Spanish content:**
- Location: `/content/es/`
- Tag: `tags: [es]`

**Shared resources:**
- Images: `/content/images/` (shared between languages)
- Use descriptive alt text in the appropriate language

### Front Matter

### Usage Checklists

**Color Usage Checklist:**

Before using a color, ask:
1. Is this interactive? → Teal for primary actions
2. Is this emphasis/personality? → Terracotta for warmth
3. Is this background/container? → Sage Green or Cream
4. Is this text? → Warm Charcoal (light) / Primary Text (dark)
5. Is this muted/secondary? → Warm Gray

**Maximum colors in one section:** 3 (base + 2 accents)

**Typography Checklist:**

Before choosing a font, ask:
1. Is this a heading? → Fraunces
2. Is this body text? → Inter
3. Is this code/technical? → JetBrains Mono
4. Is this a personal touch? → Caveat (sparingly)
5. Is this longer than 3 lines? → Never use Fraunces or Caveat

**Component Checklist:**

Before creating a component:
1. Does it follow the spacing scale? (8px increments)
2. Does it have appropriate border radius? (6px, 12px, or 16px)
3. Does it meet contrast requirements? (use WCAG checker)
4. Does it work in both light and dark mode?
5. Does it have hover/focus states for interactive elements?
